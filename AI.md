## Project 1

### Which tools did you use?

<!-- e.g. ChatGPT, Claude, GitHub Copilot, Midjourney, an image/sound generator, … -->

- Google Gemini

### What did you use them for?

<!-- Where did AI help? Ideas, writing/debugging code, creating visual or audio assets, explaining a concept, refactoring, … -->

- I used AI to help write the code. I went step by step and gave the AI my instructions. 
- With each step I used the AI as a teacher to talk me through the code and explain how it worked.
- AI also helped me to problem-solve and introduced me to new code that we haven't covered in class. 

### How did you use them?

<!-- Include the key prompts you used, or a short summary of the back-and-forth. Be specific enough that someone could follow your process. -->

- I wrote too many AI prompts to list them all here, but here are some real examples.

##### Prompt 1:
"why is the background and text not adjusting when I make the window bigger? I would like the black background to stretch across the whole screen as it's adjusted and the text to recalculate its centre point. Please explain how to update my code."

##### Prompt 2:
"Now I would like to add two important elements into this code.  First, I would like the points to disperse and rotate in a circular motion around a 3 dimensional space where the rotation point is 0,0 and the points rotate at varying distances around this point.  Next, I would like to include a mouse press: when the mouse is pressed, all the points come together smoothly like a magnet and form the word magic. When the mouse is pressed again, they disperse again to their previous rotations. How can I achieve these two things?"

##### Prompt 3:
"I'd like to add a gentle sine wave to the points when they are in "magic" form. There would be a very gentle oscillation across the whole word, meaning the word is never static on the screen. Please explain how I can achieve this."

##### Prompt 4:
"If I wanted to slightly soften the pointLight (during the "magic" section only), perhaps by softening the edges or slightly increasing the diameter of the point, how can I do this?"

### What was your own contribution?

<!-- What did YOU decide, change, reject, or build on top of the AI's output? Which creative and technical choices were yours? -->

- Every artistic choice was mine. I came up with the concept and asked AI to help build it. The mathematical choices to make it happen were AI's decision.

### Reflection

<!-- One or two sentences: what worked well, what didn't, and what you learned about using AI as a creative tool. -->

- I think this process worked well and I was happy with the result. I knew I couldn't achieve what I wanted to without AI assistance, so I worked with it to help implement my ideas and meanwhile grow my knowledge.

## Project 2

### Which tools did you use?

- Google Gemini

### What did you use them for?

- I used AI to help me combine two data sheets from ourworldindata.org.
- I used AI to help write the code. I gave AI my instructions and asked it to implement them, step by step like building blocks. 
- As this was a more complicated project with more complex code, I did not ask it to explain to me the process of each step. Instead, once the final code was finished, I went back and asked the AI to talk me through the entire code, explaining how each part works. 
- On this project I also asked AI to be creative and add anything that it thought would improve the code. It made some small but effective changes that improved the visuals and experience.

### How did you use them?

- As with Project 1, I wrote too many AI prompts to list them all here, but here are some real examples.

##### Prompt 1:
"Please create this simple code:

Please set up a white canvas that is completely responsive to screen size.

Load these files: "Top 10 Countries by Conflict Death Rate (2023).csv" and this font file name "Lexend-VariableFont_wght.ttf" with async function.

Next create a circle in the centre. No fill. Stroke weight 3px and black. Size 300 dia.

Next, add text at the top that says "Top 10 countries: Deaths from Conflict (2023)" in black."

##### Prompt 2:
"I've noticed that some of the country names are cramped and overlap when the screen has a low width. In order to combat this, I'd like to try something.

Please remove the country names from the bottom of the bar chart. Instead, please place them 20 px above each respective bar and written at a 45 degree angle. Please then add a short 2px wide line between each bar and its country name that acts as a sort of connector between the two. The start/first x,y, point should be positioned at the centre top of each bar. The second/end x,y, point should be located at the centre left of the start of the word. However, the line itself should be at a 60 degree angle. Please try this in code."

##### Prompt 3:
"My bar chart and background is not showing when I view this code in "live server" via "Visual Studio Code". What do you think is going wrong?"

##### Promp 4:
"Are there any updates you would do to improve this code and visuals? If so please apply them and I will test them."


### What was your own contribution?

- I provided all artistic direction, apart from at the very end when I asked the AI to add any final additions that it thought would improve the design. I was curious to see what it would add and was happy with the result. It had some ideas I had not thought of. 

### Reflection

- Overall this was a good process, working with AI step by step, and it allowed me to achieve things I could never achieve on my own in a short time. I enjoyed that I was still in control of the output. If I continue to use AI as both an assistant and a teacher, I can grow my knowledge and not entirely offload the task to AI. This feels like a good balance and will also sssssmake collaborations even faster in the future. As I begin to understand code structures and new functions better, I will be able to prompt more accurately and achieve even more creative and interesting results.
